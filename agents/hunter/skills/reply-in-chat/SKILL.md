# Ответ на вопрос в чате

1. Вызови `mcp__yaswami__catalog_events` — все предстоящие события города. `starts_at` — время по Данангу.
2. Пойми, что ищет человек: тему («потанцевать», «покер», «с ребёнком»), день («сегодня», «на выходных») — по вопросу и сообщениям перед ним.
3. Отбери события, которые подходят и по теме, и по дню. «Сегодня» — только сегодняшние; «на выходных» — суббота и воскресенье; день не назван — ближайшие три дня.
4. Подходящих нет — `[[пропустить: нет подходящего события]]`. Не предлагай «что-нибудь другое».
5. Есть — напиши ответ. Пример:

   ```
   Сегодня в 19:00 бачата с нуля, 150k:
   https://yaswami.com/e/…
   ```

   Или с двумя событиями:

   ```
   На выходных есть коллажный кружок в субботу в 11:00 и вечер в бане в воскресенье в 18:00:
   https://yaswami.com/e/…
   https://yaswami.com/e/…
   ```

Вопрос общий («чем заняться?») — предложи одно-два ближайших события разного типа. Вопрос не про досуг — пропусти.
