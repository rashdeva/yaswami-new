# Подбор события

1. Вызови `mcp__yaswami__collected_events_list` — это все предстоящие события города, по времени начала. `starts_at` — время по Данангу.
2. Отбери то, что подходит под вопрос: по дню («сегодня», «на выходных»), по теме (`title`, `tags`), по тому, для кого (`for_whom`).
3. Предложи не больше трёх событий, самые близкие по времени. На каждое — одна строка и ссылка:

   ```
   Пт, 19:00 — Покер, бар такой-то, 200k
   https://yaswami.com/e/…
   ```

4. Ничего не подошло — так и скажи и предложи посмотреть все события: https://yaswami.com. Не предлагай «похожее», если оно не похоже.

Цену, место и время бери только из каталога. Если поле пустое — не упоминай его, не додумывай. Записывать человека сам ты не можешь: дай ссылку, запись — на странице события.
