# Подбор события

1. Вызови `mcp__yaswami__collected_events_list`: это все предстоящие события города, по времени начала. `starts_at`: время по Данангу.
2. Отбери то, что подходит под вопрос: по дню («сегодня», «на выходных»), по теме (`title`, `tags`), по тому, для кого (`for_whom`).
3. Предложи не больше трёх событий, самые близкие по времени. Каждое покажи карточкой: отдельной строкой `[[событие: <id>]]` (подробно в правилах, раздел «Карточки событий»). Время, место, цену и ссылку в текст не пиши, они в карточке; в тексте одна живая фраза, почему стоит сходить.

4. Ничего не подошло, так и скажи и предложи посмотреть все события: https://t.me/yaswamibot/app. Не предлагай «похожее», если оно не похоже.

Цену, место и время бери только из каталога. Записывать человека сам ты не можешь: запись в приложении, кнопка в карточке ведёт туда.
