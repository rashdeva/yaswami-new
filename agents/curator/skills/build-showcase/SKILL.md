# Сборка витрины на день

1. `mcp__yaswami__admin_shelves_list` с `city_id` — что уже есть: свои полки (`author: curator`), полки команды, закреплённые (`pinned`), предложенные (`proposed`), сколько событий на каждой сейчас (`events_count`).
2. `mcp__yaswami__collected_events_list` с `city_id` — все предстоящие события. Посчитай, что есть: сколько событий сегодня вечером, на выходных, по каждой теме (`topic`), бесплатных (цена «бесплатно»), «можно без опыта» (`beginner_friendly`).
3. Реши, каких полок не хватает. Полезные почти всегда, если наберётся хотя бы 3 события:
   - «Сегодня вечером» — `rule: { period: 'tonight' }`;
   - «На выходных» — `rule: { period: 'weekend' }` (в четверг–воскресенье — выше всех, кроме «Сегодня вечером»);
   - «Можно без опыта» — `rule: { period: 'week', beginner_friendly: true }`;
   - «Бесплатно» — `rule: { period: 'week', free: true }`;
   - тематическая полка, если по теме на неделе 4+ события: `rule: { period: 'week', topic: '<тема>' }`, `topic: '<тема>'`.
   Есть такая полка у команды — свою не делай.
4. Свои полки, где событий стало меньше 3 или срок прошёл, — убери (`admin_shelves_delete`) или поправь правило. Чужие не трогай.
5. Порядок (`position`): свою полку не ставь выше закреплённой полки команды, которая стоит выше неё сейчас.
6. Каждая правка — с `note`. Создал тематическую подборку недели — поставь `ends_at` на конец воскресенья по времени города (ISO со сдвигом города, как в `starts_at` событий).
7. Проверь итог: `mcp__yaswami__showcase_get` — так видит гость (в режиме `draft` твоих предложенных полок там не будет, это нормально).
8. Ответь отчётом: строка на правку.

Не делай за раз больше 10 изменений: витрина не должна меняться у людей до неузнаваемости за одно утро.
