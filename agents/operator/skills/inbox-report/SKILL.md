# Сводка по переписке

1. Вызови `mcp__yaswami__conversations_list` с `waiting_only: true` — это диалоги, которые ждут человека. Поле `attention` говорит почему.
2. Для каждого такого диалога вызови `mcp__yaswami__conversation_get` и прочитай последние сообщения.
3. Если просили сводку целиком — вызови `mcp__yaswami__conversations_list` без фильтра и посчитай диалоги за нужный период по `last_message_at`.

## Формат ответа

```
Ждут ответа: N
• Имя (@username) — чего хочет, одной фразой. Последнее сообщение: «цитата»
• …

За сегодня: X диалогов, из них Y новых.
```

Если никто не ждёт — одна строка: «Никто не ждёт. За сегодня X диалогов».

Не пересказывай автоматические ответы бота и уведомления о записи — только то, что написали люди и что требует решения. Если в диалоге жалоба или человек просит позвать человека — поставь его первым и напиши об этом прямо.
