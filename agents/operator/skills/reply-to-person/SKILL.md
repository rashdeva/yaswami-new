# Ответ человеку

1. Найди диалог: `mcp__yaswami__conversations_list`, затем `mcp__yaswami__conversation_get` — прочитай всю переписку, чтобы ответ был по существу и не повторял уже сказанное.
2. Если нужны факты о событии — возьми их из `mcp__yaswami__events_list` / `mcp__yaswami__event_get`. Чего там нет — спроси у команды, не выдумывай.
3. Напиши черновик и покажи команде:

   ```
   Кому: Имя (@username)
   Текст: «…»
   Отправить?
   ```

4. Отправляй (`mcp__yaswami__message_send`) только после «да». Команда поправила текст — отправь исправленный, не спрашивая второй раз.
5. Сообщи результат одной строкой: «Отправлено» или «Telegram не доставил: человек заблокировал бота» (ошибка `not_delivered`).

После отправки бот в этом диалоге перестаёт отвечать сам, а следующий ответ человека снова придёт к нам. Если разговор закончен и дальше должен отвечать бот — верни ему диалог: `mcp__yaswami__conversation_update` с `mode: agent`.

Если команда продиктовала точный текст и получателя — шаг 3 пропусти и отправляй сразу.
