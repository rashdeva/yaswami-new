# Афиша недели

Карусель 1080×1350 (4:5) из живой витрины города: обложка с иллюстрацией, по слайду на день с тремя лучшими событиями,
последний слайд — куда идти записываться. Рядом — `caption.txt`, текст поста для Instagram или Telegram-канала.

```bash
node packages/poster/src/cli.ts --city danang --from 2026-11-26
```

Флаги: `--days 7`, `--out poster-out` (папка в `.gitignore`), `--api https://yaswami.com` (по умолчанию прод; читаются
только публичные ручки `/cities`, `/collected-events`, `/config`, так что подойдёт и локальный API).

## Как устроено

- `pick.ts` — какие события попадут в афишу: популярные и с обложкой выше, тема за день не повторяется, одно и то же
  регулярное событие за неделю берётся один раз, пустые дни выпадают. Проверяется `pick.test.ts`.
- `render.ts` — слайды. satori (flexbox → SVG) и resvg (SVG → PNG), без браузера: тот же код можно запускать на сервере
  по расписанию. Цвета тем берутся из `apps/web/src/tokens.css`, иконки — из `apps/web/public/topics`, знак — `mark.svg`.
- `caption.ts` — текст поста по тем же дням и событиям.
- `assets/<город>.png` — обложка города в стиле иконок тем (глянцевый 3D «желе», фон `#fcf5ea`). Рисуется через Codex
  с иконками тем как образцом; у города без обложки — обложка без картинки. Предложный падеж города («в Дананге») —
  в `CITY_ART` в `cli.ts`, в базе его нет.

Подсмотрено у городских медиа (`docs/research/city-media-afisha.md`): 4:5, крупный заголовок-вопрос, пилюли-оглавление
на обложке, единый фон и шапка у всех слайдов, «Сохрани, чтобы не потерять» в конце.
