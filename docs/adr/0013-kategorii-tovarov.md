# Десять категорий товаров вместо «Еды» и «Хендмейда»

У Товара (Product) было две категории, `food` и `handmade`, и во вкладке «Товары» две плашки. Разведка ([product-categories-2026-11.md](../research/product-categories-2026-11.md)) показала, что так нельзя найти то, что ищут:
- **Предложение — почти одна еда.** Около 530 позиций в каналах мастеров Дананга, из них ~85% — меню двух мастеров.
- **Ищут конкретное.** Торт на заказ, хлеб на закваске, творог, соленья, свечи.
- **В одной плашке «Еда» спрос и предложение расходятся.** Творог тонет среди 180 обедов, а пельменей и обедов, которых в предложении больше всего, почти не спрашивают.

## Решение

У товара одна **категория товара** (`category`) из списка `PRODUCT_CATEGORIES` в `packages/core`:

| категория | что это |
|---|---|
| «Выпечка и десерты» | |
| «Пельмени и полуфабрикаты» | |
| «Готовая еда» | |
| «Молочное и сыр» | |
| «Заготовки и деликатесы» | |
| «Напитки» | |
| «Фермерское» | то, что продавец вырастил сам |
| «Косметика и мыло» | |
| «Одежда и украшения» | |
| «Дом и подарки» | |

- **Устроено как категории услуг** (ADR-0012). Список в коде, у категории `slug`, название, эмодзи и `what`. По `what` ИИ ставит категорию при разборе поста, команда правит её в «Каталоге».
- **Плашки — только непустые.** Гость видит плашки тех категорий, где в его городе есть товары: `products/list` отдаёт `categories`. Одна категория на город — плашек нет.
- **Пометки о составе — не категория.** «Без сахара», «без глютена», «ПП», «веган» пересекают все группы еды и встречаются у двух мастеров. Они остаются в описании товара, отдельного поля нет.
- **Фермерское берём** — от того, кто вырастил сам. Перекупленное на рынке — перепродажа; эту границу держит ИИ.

Старые товары не переразмечаем. Опубликованных на проде не было, поэтому миграция удаляет товары и сбрасывает отметки источников товаров. Сборщик перечитывает их последние посты и собирает заново, уже с новыми категориями.

## Почему не иначе

- **Две верхние группы «Еда» и «Хендмейд» с подкатегориями.**
  - Человек не ищет «еду»: он ищет торт или творог.
  - Почти всё — еда, поэтому верхний уровень ничего не отбирает и только добавляет нажатие.
- **Одна категория «Хендмейд».** Хендмейд делят по назначению — тело, одежда, дом, — так и у ikman, и у Etsy. Слово «хендмейд» человек не ищет: он ищет серьги, мыло, свечу.
- **Полуфабрикаты вместе с готовой едой.** Так проще, но мастера сами делят «заморозку» и «на сегодня», и сценарии разные. Вместе это 350 позиций из 530: одна плашка вытеснила бы всё остальное.
- **Категории в базе и правка из админки, как у тем событий.** Это следующий шаг, общий для услуг и товаров (задача в GitHub). Пока список меняется вместе с подсказкой ИИ и отбором постов, то есть кодом.

## Consequences

- **База.** `products.category` — новый список (миграция `product_categories`). Товары, собранные до неё, удалены и собираются заново.
- **Сборщик.**
  - В подсказке ИИ — категории с `what`, фермерское и пометки о составе в описании.
  - В дешёвом отборе — признаки хендмейда и фермерского.
  - Охотник ловит вопросы про йогурт, соленья, сало, мёд, браслеты.
- **API, сайт и мобильное.** `ProductList.categories`; плашки и заглушки без фото — по категориям.

## Когда пересматривать

- Если категорию часто правят руками — список неудачный.
- Если в одной категории копится непохожее — делить.
- Если категория месяцами пустая во всех городах — сливать: первые кандидаты `drinks` и `cosmetics`.
