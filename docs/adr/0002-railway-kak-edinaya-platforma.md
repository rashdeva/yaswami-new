# Railway как единственная платформа; PostGIS-образ и Buckets выбраны сразу

Всё приложение — SSR-веб, MTProto-воркер, job-воркер, Postgres и файлы — живёт в одном проекте Railway (~$27–30/мес). Альтернатива Fly.io + Supabase обошлась бы в $40–50 при двух дашбордах и сетевой задержке между воркерами и БД; её единственные преимущества (мультирегион, готовые auth/realtime/RLS) нам не нужны.

## Consequences

- Postgres разворачивается из шаблона `postgresql-extensions` (PG 18) с **PostGIS**, `pg_trgm` и `pgmq` — дефолтный managed-Postgres Railway PostGIS не поддерживает и поддерживать не планирует. Переезд на другой образ позже означает dump/restore, поэтому образ выбран до первой миграции.
- Очередь задач — **pgmq в той же БД**, без отдельного брокера.
- Расписание опроса Source хранится в своей таблице; Railway-cron (минимум 5 минут, UTC, зависший запуск молча пропускает следующие) используется только чтобы будить планировщик.
- Файлы (превью афиш) — **Storage Buckets**, не volume: volume привязан к одному сервису и одному писателю, а писать афиши будет воркер и отдавать веб. Buckets дешевле в 10 раз ($0.015/ГБ), egress бесплатный, ссылки — presigned.
- На MTProto- и job-воркерах тумблер Serverless/App Sleeping должен оставаться выключенным.

## Копия для другой страны

Другая страна со своим ботом (например, Узбекистан и `@uzyaswamibot`) — отдельная копия проекта Railway (Duplicate project) из того же репозитория. У неё своя база, свой бот, свои аккаунты сборщика и источники; код общий, и `main` выкладывается в обе копии. Город страны в общей копии подошёл бы, если бы хватало одного бота.

Что отличает копию — только переменные:

- `BOT_TOKEN` — нового бота; имя сервер узнаёт сам (`getMe`), из него собираются ссылки и кнопка «Открыть афишу». У бота в @BotFather завести мини-приложение с коротким именем `app` (иначе `APP_NAME`) и Login Widget с доменом копии (`TG_CLIENT_SECRET`).
- `DEFAULT_CITY_ID` — у API и сборщика, например `tashkent`. При старте `migrate.ts` ставит его значением по умолчанию колонок `city_id`, если такой город уже есть в `cities`; сервис без этой переменной колонки не трогает.
- Свои `PUBLIC_URL`, `ADMIN_IDS`, `COLLECTOR_SECRET`, `ACCOUNTS_KEY`, `TG_SESSION` и бакет медиа; роли Hermes — своя копия `agents/` со ссылками на нового бота, их адреса и ключи (`SUPPORT_URL` и соседи) или пусто.

Порядок первого запуска: копия стартует с городами из миграций (Дананг и Шри-Ланка) → в админке, «Города», добавить города страны → задать `DEFAULT_CITY_ID` и перезапустить API и сборщик → отправить чужие города в архив. Пока город по умолчанию не тот, он в архив не уходит.
