# Пользователь больше не равен id в Telegram

До приложения для телефона каждый пользователь входил через Telegram, и `users.id` был его id в Telegram. App Store требует вход через Apple, раз есть вход через Telegram (правило 4.8), — появляются люди без Telegram. На Android тем же путём добавлен вход через Google (`provider = 'google'`): он не обязателен, но открывает приложение тем, у кого нет Telegram.

Решение:

- **Отрицательные id.** Вошедший не через Telegram получает id из последовательности Postgres `users_local_id_seq` (−1, −2, …). Id пользователей Telegram положительные, так что пересечься они не могут, а знак сразу говорит, есть ли у человека Telegram (`hasTelegram` в `telegram.ts`).
- **Таблица способов входа** `user_identities (provider, subject, user_id)`: кем человека знает поставщик (`apple` и его `sub`). Вход через Telegram туда не пишется — его subject и есть `users.id`.
- **Бот не пишет тем, у кого нет Telegram,** — проверка одна, в `bot.call` и `bot.send`, а не у каждой отправки (уведомления, отзывы, переписка).

Почему не иначе:

- **Свой id-uuid у всех пользователей, Telegram id — в колонку.** Правильнее, но `users.id` — внешний ключ в десятке таблиц (события, гости, токены, контакты, заходы, отзывы, переписка по `peer_id`), его же знают сборщик, журнал команды, `ADMIN_IDS`, ссылки `-r<id>` и агенты через MCP. Переезд — миграция всех этих мест одним махом ради одного нового способа входа.
- **Подставной положительный id из большого диапазона.** Telegram выдаёт id без обещанной верхней границы; пересечение со временем стало бы чужим аккаунтом.

## Consequences

- Схемы и маршруты, принимающие id пользователя, не требуют, чтобы он был положительным.
- Человек, вошедший и через Telegram, и через Apple, — два пользователя. Склейки нет.
- Организатор из Apple не связывается с собранным профилем (`hosts.telegram_id`): связь идёт только через Telegram.

## Когда пересматривать

Когда понадобится склейка аккаунтов (экран «привязать Telegram»): строка `user_identities` переезжает к Telegram-пользователю, а данные отрицательного id переносятся на него. Если способов без Telegram станет больше, чем людей из Telegram, — пора к своему id у всех.
